This release fixes the tool list for clients built on the TypeScript MCP SDK.

## Fixed

- **The tool list now loads in every client.** In the output schema of the 15 write tools, the `body` field was typed as the bare JSON Schema `true`. That is valid JSON Schema, but the MCP schema wants an object there, and clients built on the TypeScript SDK, Glama's checker among them, refused the whole tool list. `body` now has a proper schema with a description, and a new test checks every property schema of every tool so it cannot come back.
